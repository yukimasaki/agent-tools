# Security Policy

## Supported versions

Only the latest release (the `main` branch) is supported.

## Reporting a vulnerability

**Please do not open a public issue for security vulnerabilities.**

Use GitHub's Private Vulnerability Reporting:

→ [**Report a vulnerability**](https://github.com/yukimasaki/agent-tools/security/advisories/new)

You should receive an initial response within 7 days.

## Scope

Covered:

- Code in this repository (`plugins/**`, `tests/**`, workflows)
- The marketplace manifest (`.claude-plugin/marketplace.json`) and plugin manifests

Not covered:

- herdr itself — report to the herdr project
- Claude Code, Codex, or Pi themselves — report to their vendors
